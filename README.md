# freefall-weather
自由降下訓練向け気象分析アプリ

## 開発時の確認

```bash
python -m unittest discover -s tests -v
python -m py_compile scripts/*.py
```

`index.html` はGitHub Pages向けの画面です。Pagesワークフローは公開に必要な
`index.html`、`data/gfs_winds.json`、取得済みの `data/aviation_weather.json` を
`_site` に配置して配信します。

> このアプリは訓練実施可否を判定するものではありません。現地観測、公式な
> 気象情報、部隊の正式な基準を確認してください。

## 参照地点

- 霧島演習場周辺（暫定）
- 南種子町周辺（暫定）
- 東富士山内台DZ: MGRS 54SUE 0784 0435
  （WGS84換算: 35.26385539, 138.88753204、モデル標高約464m MSL）
- 習志野演習場周辺（暫定）: MGRS 54SVE 1651 5209
  （WGS84換算: 35.70722400, 140.07658381）

習志野の代表点は利用者指定のMGRS座標をWGS84緯度経度へ換算した暫定値です。
座標系・原点・正式な降下地点・地表標高は、正式資料と照合してください。

NOAA GFSの選択可能な予報時刻は、3時間先から72時間先まで3時間間隔です。
高度別風は気圧面データの風ベクトルを、モデル地表標高から200～6,000m AGLまで
200m間隔で線形補間して表示します。地表標高はOpen-Meteo標高モデルの概算値で、
測量値ではありません。元データの高度範囲外は補外せず「不明」とします。
高度別グラフの右欄では400mごとに風向矢印を表示します。角度は気象学上の
「吹いてくる方向」、矢印は北を上にした「風が吹いていく方向」です。

着地地点は地域選択と連動し、次のMGRSへ自動的に切り替わります。

- 習志野演習場: `54SVE16515209`（指定表記: 54SVE 1651 5209）
- 霧島演習場DZ: `52SGB12448691`（指定表記: 52SGB 1244 8691）
- 前之浜DZ（種子島）: `52RFU83336085`（指定表記: 52RFU 8333 6085）
- 東富士山内台DZ: `54SUE07840435`（指定表記: 54SUE 0784 0435）

- 東富士山内台DZ境界: `54SUE08410127`、`54SUE09620217`、`54SUE09730261`、`54SUE07370638`、`54SUE05610411`
- 習志野演習場境界: `54SVE14795263`、`54SVE14825215`、`54SVE17285150`、`54SVE17505241`、`54SVE15685314`、`54SVE14845266`

入力欄では空白を省略した正規化表記を使用します。参考経路は選択したGFS風を
200m層ごとに積算し、入力した降着点から逆算した降下開始点を求める単純な受動ドリフト推定です。
自由降下率と開傘後降下率は入力値を使いますが、操舵、水平対気速度、機体運動、加減速、
局地風、乱流は計算に含みません。

東富士と習志野では、指定されたMGRS境界を多角形として地図に表示し、逆算した降下開始点が
境界内かを判定します。必要開始点が境界外で、経路が途中から境界内へ入る場合は、場外の降下を
表示せず、最初の場内点をホールドエリアとして、それより上の高度処理を同一点に紫色で表示します。
場内進入後は入力した降着点までの風ドリフト経路を表示します。これは操舵で風を相殺できると仮定した
概念表示であり、傘の水平対気速度、旋回半径、操舵余裕は計算していません。実行可能性を保証しません。
種子島は場内開始判定の対象外、霧島は境界未登録のため判定不能です。境界上・座標換算誤差を含むため、
実際の降下計画、降下開始点又は着地点の決定には使用できません。

強風時の処理プロンプト：

> 必要な受動ドリフト開始点が指定境界外になる場合、場外で降下を開始しない。降着点から逆算した
> 経路が初めて場内へ入る最高高度を求め、それより上は同一点のホールドエリアで高度処理する概念表示とし、
> 場内進入後のみ降着点への風ドリフト経路を表示する。操舵能力・旋回半径・対気速度を計算していないため、
> 実行可能性は保証せず要確認とする。

経路算定時はGFS気圧面の総雲量を200m AGL間隔に補間し、各経路点の推定雲量を表示します。
推定雲量50%以上の区間は地図上の太い灰色破線と、時間×高度の重ね合わせ図で強調します。
これは地域代表点のモデル値を経路へ適用した参考表示で、局地雲、雲内視程、地形・構造物等の
実際の障害又は経路通過可否を判定するものではありません。

算定後の参考経路はOpenStreetMap上に表示し、自由降下区間、開傘後区間、降下開始点、
開傘点、着地点を色分けします。地図表示にはLeafletとOpenStreetMapタイルへの通信が必要です。

### 傘種性能プリセット

- RA-1: 降下率4.0m/s、前進速度13.4m/s、滑空比3.5:1
  （Airborne Systems `RA Intruder Family of Systems` 公開仕様）
- MC-4: 全滑空降下率14～16ft/s（4.3～4.9m/s）、算定プリセット4.6m/s、
  前進速度10～25mph、滑空比3:1
  （Headquarters, Department of the Army, TM 10-1670-287-23&P, Change 1, WP 0002 00-14）

MC-4の4.6m/sは公開範囲の中間値です。実際の降下率は懸吊重量、ブレーキ量、姿勢等で
変動します。傘種選択で降下率プリセットを入力しますが、画面上で修正できます。
前進速度と操舵は現行の受動ドリフト算定には使用しません。

### 航空気象・危険気象

GitHub ActionsがUS Aviation Weather Center公開APIから30分ごとに取得した情報を表示します。
対象空港は霧島がRJFK/RJFM、種子島がRJFG/RJFK、東富士がRJNS/RJTT、習志野がRJAA/RJTTです。
表示対象は空港METAR/TAFの雲底・航空視程・雷・ウインドシアと、福岡FIR全域の
国際SIGMET（乱流・火山灰）です。

空港観測・予報は演習場の現地観測ではなく、SIGMETは福岡FIR全域の情報です。
「明示なし」は現象が存在しないことを保証しません。実施可否の判定には使用せず、
気象庁・航空気象官署等の公式情報、現地観測及び正式な基準と照合してください。

航空気象横断図は、選択地域の空港METAR/TAF（雲底・視程・雷・ウインドシア）、
選択中のGFS高度別風、福岡FIRの乱流・火山灰SIGMETを高度方向に併記する教育用概念図です。
GFSと空港情報はAGL、SIGMETはFL/MSL相当であり、地点・高度基準・対象範囲が異なります。
実測された地点間断面又は飛行経路上の断面ではありません。

雲層の時間推移はGFS気圧面相対湿度を200m AGL間隔に線形補間し、RH 80%以上の層を
3時間ごとの時間高度断面として表示します。これは潜在的な雲層を把握するためのモデル推定で、
実際の雲底、雲頂又は雲厚の観測値ではありません。元の気圧面範囲外は補外しません。
